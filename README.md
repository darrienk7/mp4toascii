# MP4 to ASCII video PYTHON

Plays an mp4 video of choice in the terminal
Works with MacOS, Windows, any mp4 video

---

## Supported Video Formats

- MP4 (.mp4)

- MOV (.mov)

- MKV (.mkv)

- AVI (.avi)

- WebM (.webm)

---

## How to use

- Make a venv and download the dependencies listed in pyproject.toml
- Drag your mp4 files into the **Source Videos** folder
- **Optional** Change the grayscale ASCII ramp (Pre installed: 70 Character ramp) in config.toml
- Run run.bat on Windows or run.sh on MacOS
- Choose the video of choice and to play it in color or not
